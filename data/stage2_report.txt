Воспроизведение
Рабочая директория: /Users/kirillsaidashev/Documents/Projects/dadhouse
Blender 5.2.1 LTS, системный Python 3.12 + Pillow; Arial из macOS.
Дополнения и внешние текстуры не нужны. Работать отдельным фоновым
процессом Blender. В этой среде запуск в песочнице ломает Metal;
использован разрешённый запуск CLI вне песочницы.

python3 -m unittest discover -s tests -p 'test_*.py'
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --offline-mode --python-exit-code 1 --python scripts/blender_stage2.py -- build
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --offline-mode --python-exit-code 1 --python scripts/blender_stage2.py -- verify
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --offline-mode --python-exit-code 1 --python scripts/blender_stage2.py -- test
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --offline-mode --python-exit-code 1 --python scripts/blender_stage2.py -- preview
python3 scripts/report_stage2.py
python3 -c 'import sys,json; sys.path.insert(0,"scripts"); from source_stage2 import diagram; diagram(json.load(open("data/house_stage2_geometry.json")))'

build сверяет хеш существующей сцены с квитанцией. Ручные правки не
перезаписываются: используется отдельный house_stage2_revision.blend;
если он уже существует, сборка прекращается. verify/preview/test работают
с house_stage2.blend. Ревизию нужно сначала отдельно просмотреть.
source_stage2.py не запускать для обновления реестра: он намеренно
отказывается перезаписывать существующий JSON с уточнениями пользователя.
